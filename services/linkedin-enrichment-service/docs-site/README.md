# Documentation Site

This directory contains the Docusaurus-powered documentation for the LinkedIn Enrichment Service.

## Quick Start

The documentation is automatically served when you start the main service at `/docs`:

```bash
# From the service root directory
npm run dev

# Then visit:
http://localhost:4200/docs
```

## Structure

- `docs/` - Documentation pages
- `docs/api/` - Auto-generated from OpenAPI spec
- `src/` - Custom React components
- `static/` - Static assets
- `docusaurus.config.ts` - Main configuration
- `sidebars.ts` - Sidebar structure

## Features

✅ Interactive API reference
✅ Dark mode support  
✅ Full-text search
✅ Mobile-responsive
✅ Syntax highlighting
