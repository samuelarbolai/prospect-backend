REST API for the Prospect Pipeline Backend service. Manages prospects, enrichment queuing,
outreach tagging, and pricing sessions.

**Features:**
- Query and filter prospects with pagination
- Queue prospects for LinkedIn and domain enrichment
- Tag prospects as outreach ready
- Track pricing and billing for enrichment operations

**Technology Stack:**
- Express.js with TypeScript
- Google Cloud Firestore for data storage
- AWS SQS for job queuing (optional)
- Zod for request validation
